# 夏希漢化網站作業規則

## SEA 維修公告圖片

- SEA 維修公告是主頁同步資訊，不需要放官方公告最上方的通用 PATCH NOTE 預覽圖。
- 若維修公告正文另有角色預覽、造型、系統說明、數值圖表或其他實質內容圖片，夏希漢化首頁仍須放入對應圖片，不得只保留文字。
- 圖片須放在相對應的更新章節，維持原公告順序，並沿用網站既有的點擊放大與手機版顯示功能。
- 優先使用官方原始圖片網址；若官方來源無法外部顯示、載入異常或有引用限制，先回報後再決定是否改為網站自行託管。
- 圖片若含有需要翻譯的文字，必須直接重製圖片內文字的繁體中文版；不能只在圖片旁補充譯文，也不能直接保留未翻譯的原文圖片。
- 圖內文字重製須盡量保留原圖的字型風格、字重、描邊、陰影、配色、位置、構圖與原意，並以使用者提供的成品比對圖作為視覺驗收基準。
- 此類圖片由使用者決定並調整模型與推理強度，以達到所需的文字辨識、翻譯與視覺還原品質；若素材或譯意不明，應先提出確認，不得自行猜測或降低標準。
- 網頁發布後須同時確認圖片載入、點擊放大、手機版不裁切，以及 `data/notices.json` 的公告圖片欄位是否同步更新。

## 網站版本號

- 使用者要求更新「版本號」時，必須同步更新首頁漢化狀態面板的「官方版本（Ver.x.x.x）」與下載區塊的「CURRENT BUILD · x.x.x」。
- 發布前須搜尋舊版本號，確認首頁兩處皆已更新且沒有殘留。
