# 夏希漢化網站作業規則

## SEA 維修時間標籤

- 首頁 SEA 維修公告的 UTC+8 時段一律顯示「SGT／台灣時間」。台灣與新加坡時差為零，沿用官方公告的日期與時段。公告 JSON 的時區代碼維持 `SGT`，中文標籤取自首頁。

## SEA 維修公告圖片

- SEA 維修公告是主頁同步資訊，不需要放官方公告最上方的通用 PATCH NOTE 預覽圖。
- 若維修公告正文另有角色預覽、造型、系統說明、數值圖表或其他實質內容圖片，夏希漢化首頁仍須放入對應圖片，不得只保留文字。
- 圖片須放在相對應的更新章節，維持原公告順序，並沿用網站既有的點擊放大與手機版顯示功能。
- 優先使用官方原始圖片網址；若官方來源無法外部顯示、載入異常或有引用限制，先回報後再決定是否改為網站自行託管。
- 圖片若含有需要翻譯的文字，必須直接重製圖片內文字的繁體中文版；不能只在圖片旁補充譯文，也不能直接保留未翻譯的原文圖片。
- 圖內文字重製須盡量保留原圖的字型風格、字重、描邊、陰影、配色、位置、構圖與原意，並以使用者提供的成品比對圖作為視覺驗收基準。
- 此類圖片由使用者決定並調整模型與推理強度，以達到所需的文字辨識、翻譯與視覺還原品質；若素材或譯意不明，應先提出確認，不得自行猜測或降低標準。
- 網頁發布後須同時確認圖片載入、點擊放大、手機版不裁切，以及 `data/notices.json` 的公告圖片欄位是否同步更新。

## SEA 維修公告引用連結

- SEA 維修公告若引用另一篇活動或更新公告，且夏希漢化已有對應繁中頁，須在同一項目中同時提供「夏希漢化繁中頁」與「SEA 官方原文頁」。
- 兩個連結必須明確標示，不得只以相同標題呈現而讓玩家無法辨識來源。
- 若夏希漢化尚未製作對應繁中頁，先只放 SEA 官方原文頁，不得建立不存在或預計未來才會完成的連結。
- 維修公告最下方仍須保留該篇維修公告本身的 SEA 官方原文連結。
- `data/notices.json` 的 SEA 維修公告正文必須取自主頁維修區塊，不得因區塊內含本機活動連結，而誤用被連結活動頁的正文。

## 首頁新增角色與活動橫幅

- 綠色「新增角色」區塊只用一行顯示 SEA 維修實際新增的角色名稱，例如「新增角色：吉賽爾」。不加入韓版角色預告、活動名稱或角色連結。
- 「NEXT UPDATE」只在 SEA 維修有新增活動，且相應活動翻譯完成後，更新該次日期與活動的繁中名稱。若該次維修沒有新增活動，沿用上次的日期與內容。

## 網站版本號

- 使用者要求更新「版本號」時，必須同步更新首頁漢化狀態面板的「官方版本（Ver.x.x.x）」與下載區塊的「CURRENT BUILD · x.x.x」。
- 發布前須搜尋舊版本號，確認首頁兩處皆已更新且沒有殘留。

## 季度角色總覽模板

- 以 `winter-2026-character-preview/` 作為未來季度／多角色搶先看頁面的基礎模板，沿用既有韓版角色頁白底樣式。
- 桌面右上固定索引與手機角色選單，依角色名稱連至各自的介紹區塊；不要使用「姿勢1／姿勢2」或技能編號來導覽多角色總覽。
- 保留官方圖文順序，人物長圖適度縮小並可點擊放大；武器、防具、姿勢資訊同時提供可搜尋的文字表格。官方有動圖時才加入對應動畫，不建立空的技能或動畫區塊。
- 作者指定「暫譯」的名稱，正文、表格及圖內文字均須保留該標記；暫用核可不得視為正式定名或 GE Catalog 正式收錄。
- 首頁仍按既有韓版新資訊排序、六張收合及公告 JSON 自動生成規則發布；韓版預告不得表述為 SEA 已確定推出。
